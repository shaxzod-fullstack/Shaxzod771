## Featured Projects

### [Portfoliyo](https://github.com/Shaxzod771/Portfoliyo)

A personal portfolio whose content — projects and incoming messages — is managed from its own
admin panel instead of being hard-coded.

- Public site in Vue 3 + Pinia with three languages (UZ / EN / RU)
- Admin panel for project CRUD with reordering and image upload, plus a contact-message inbox
- PHP 8.3 REST API with first-run admin setup, login throttling, a password policy and TOTP two-factor authentication
- Session management (list and revoke active sessions) and an authentication log
- Front end deployed to GitHub Pages through a GitHub Actions workflow

In progress (not yet published): the API is being moved to Laravel 13 with a PHPUnit feature-test suite and a CI workflow.

## Engineering Practices

- **REST APIs** — JSON endpoints with validation, separate public and admin routes
- **Authentication** — throttled logins, password rules, TOTP two-factor authentication, revocable sessions
- **Database** — MySQL schemas and Laravel migrations; tests run on in-memory SQLite
- **Testing** — PHPUnit feature tests, including checks that admin routes refuse guests
- **Code style** — Laravel Pint
- **Configuration** — environment files with `.env.example` templates; secrets stay out of Git
